

# Docker Swarm CI/CD Project using Jenkins

## Project Overview

This project demonstrates a **complete CI/CD pipeline using Docker Swarm and Jenkins** to deploy multiple banking microservices.

The pipeline performs the following tasks:

1. Fetch source code from GitHub
2. Build Docker images
3. Tag Docker images
4. Push images to DockerHub
5. Deploy containers using Docker Swarm

The project simulates deployment of the following services:

* Internet Banking
* Mobile Banking
* Insurance
* Loan Services

These services are containerized using Docker and deployed across multiple nodes using Docker Swarm.

---

# Architecture

Developer → GitHub → Jenkins Pipeline → Docker Build → DockerHub → Docker Swarm Cluster → Running Containers

Infrastructure includes:

Manager Node
Worker Node 1
Worker Node 2

The manager node orchestrates the swarm while worker nodes run application containers.

# Step 1: Install Docker on All Nodes

Run the following command on all instances.

```
yum install -y docker
systemctl start docker
```

---

# Step 2: Configure Hostnames

Manager Node

```
hostnamectl set-hostname manager
```

Worker Node 1

```
hostnamectl set-hostname worker1
```

Worker Node 2

```
hostnamectl set-hostname worker2
```

---

# Step 3: Initialize Docker Swarm

Run on Manager Node

```
docker swarm init
```

This initializes the swarm cluster and generates a join token.

---

# Step 4: Join Worker Nodes

Run the join command generated by the manager on each worker node.

Example

```
docker swarm join --token <TOKEN> <Manager-IP>:2377
```

Verify nodes in the cluster

```
docker node ls
```

---

# Step 5: Install Jenkins

Create a script file

```
vi Jenkins.sh
```

Paste Jenkins installation script and run

```
sh Jenkins.sh
```

Access Jenkins using browser

```
http://<Manager-IP>:8080
```

---

# Step 6: Allow Jenkins to Access Docker

Run on manager node

```
chmod 777 /var/run/docker.sock
systemctl daemon-reload
systemctl restart docker.service
```

This allows Jenkins pipelines to execute Docker commands.

# Jenkins Pipeline Script

```
pipeline {
    agent any
   
    stages {

        stage('checkout') {
            steps {
                git 'https://github.com/Divyasri-div/dockerproject.git'
            }
        }

        stage('build') {
            steps {
                sh 'docker build -t $image .'
            }
        }

        stage('tag') {
            steps {
                sh 'docker tag $image $repo'
            }
        }

        stage('push') {
            steps {
                sh 'docker login -u divyasri52 -p $password'
                sh 'docker push $repo'
            }
        }

        stage('deploy') {
            steps {
                sh 'docker stack deploy bank -c docker-compose.yml'
            }
        }
    }
}
```

# Step 9: Docker Compose File

docker-compose.yml

```
version: '3.8'

services:

  internetbanking:
    image: divyasri52/ib-image:latest
    ports:
      - "81:80"
    deploy:
      replicas: 3
    volumes:
      - /var/lib/internetbanking

  mobilebanking:
    image: divyasri52/mb-image:latest
    ports:
      - "82:80"
    deploy:
      replicas: 3
    volumes:
      - /var/lib/mobilebanking

  insurance:
    image: divyasri52/insurance-image:latest
    ports:
      - "83:80"
    deploy:
      replicas: 3
    volumes:
      - /var/lib/insurance

  loan:
    image: divyasri52/loans-image:latest
    ports:
      - "84:80"
    deploy:
      replicas: 3
    volumes:
      - /var/lib/loan
```
